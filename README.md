# 古代官员升职记 · 县府四任

[线上游戏 · GitHub Pages](https://lynch715.github.io/ancient-official-simulator/)

当前版本 v0.16（存档 v12）。通判、同知、知府各新增18件剧情、4件GitHub古代公案改编，原24条主线公文重写；同次仕途各触发一次，来源、玩法和兼容见 [案件来源与剧情扩充](案件来源与剧情扩充_v0.16.md)。v0.15 修正手机上“可用精力”徽章溢出，并禁止双指与双击缩放。开局可选严苛或常例难度；试玩发现与调整见 [试玩报告_v0.14](试玩报告_v0.14.md)。严苛难度已覆盖知县、通判、同知、知府四任，府任部分见 [严苛府任说明](严苛府任说明_v0.13.md)。v0.12 的界面、流水与文字修复见 [修复验收_v0.12](修复验收_v0.12.md)。新开知县任期为严苛难度，见 [严苛难度说明](严苛难度说明_v0.11.md)；最新规则见 [玩家办事指南](玩家办事指南_v0.11.md)。v0.10 审计见 [审计报告](审计报告_v0.10.md)。

明代中期题材的单机地方治理模拟。玩家以进士身份外授知县，在三年156周任期内安排经济、民生、断案、工程和赈灾，考满称职后可获授府通判，再完成三年156周府级粮运任期；称职后可接任同知，统筹第三个三年156周的河工赈济；称职后获授知府，进入第四个三年156周府政统筹任期。地点、人物为虚构，历史制度经过玩法简化。

## v0.11 严苛难度

新开局的知县任期改为严苛难度：开局银粮减半，季末实解上解，旱涝周次与轻重随种子变化，另有摊派、虫灾、秋汛；全县指标每周回落，考评按全任平均与期末各半、无参与分；案卷可凭部分证据拟判但有退回风险，16周逾限，两案可和息；私产可聘书启换精力。旧档沿用常例规则。v0.13 起，严苛知县升任后的通判、同知、知府也按严苛规则。

## 当前可玩范围

- 三种出身、三种主角形象；按周推进的完整三年156周任期。
- 七个主要页面：公堂、辖地、案牍、钱粮、县政、官署、仕途。
- 四项工程、四类具有固定事实、立卷后不变的案件、县级与通用事件、灾前准备与灾后安置；另有8类周间日常及8条条件后续，各版只展示一次；第二、第三年新增18件阶段事务，查验与交付按期限留下实际结果。工程26周，复核2周，协济2周，采购1周，复耕反馈4周。
- 官银、仓粮、私产分账；协济、采购和复核按实际到期结算。
- 役政、市政、安民三类持续方针；四处独立辖地、人物互信与协作减费、阶段地方要务、判后执行、工程修复和欠付清偿。
- 决策与周末均有实际结算回执，列出变化前后与公私账目；预算单列为估算。
- 新增府通判可玩任期：三县调粮、常路与急运、账实核查、府仓维护、8项府级公文、考满及两任履历。
- 167 项玩法自动化测试通过，覆盖周历、v1/v2旧档迁移、年度秋收、事务原子性、重复命令、延期到账、灾情、判后执行、政策停支及完整156周治理任期。
- 14 张场景、21 张透明人物立绘、19 张头像、32 个手绘 SVG 图标；共 86 个资源 ID、119 个运行文件。按钮没有使用 Emoji。缺失素材有预留占位和自动降级。
- 自动存档、上一份备份、JSON 文件导入导出、文本备份恢复。存档版本v12；旧季度档自动换算为周，旧周制档补齐县政数据，既有钱粮、证据与选择保留。旧档已结案卷不追加执行责任。

v0.10增加逐周保存的常例推进、18件阶段事务、分阶段地方交验和积案补查移交。新县任称职须同时办完四案复核与执行；已考满旧档保留原资格。开集按生产、秩序和季节增收，工役方针无在建工程时停支。

v0.9增加人口去向账、按状况折算县内工程效力、饱和动作停用、差费优惠与底册次数；手机地图使用紧凑标签与独立44像素触控区。县任及知府每类案卷有三个固定版本，合计18个案情，新局选择后随履历锁定。

当前可玩范围为知县、分管粮运的府通判、分管水利赈济的同知、统筹三县的知府四任。按察司副使及更高职务、完整三年留任重开仍未实现；知府结局明确标示这一范围。96 条设计种子不等于 96 个已经可以触发的游戏事件。

新增同知任期：八份公文、三项跨县工程、勘查报批和质量返工、三次汛期、口粮与复耕安置、独立专项账目。详见 [同知任职说明_v0.5.md](同知任职说明_v0.5.md)。

新增知府任期：三县预算差事、报表与现场核验、属官调查及接任、两宗跨县案卷、承接旧河工和待安置居民、12次阶段考核、8份公文。详见 [知府任职说明_v0.6.md](知府任职说明_v0.6.md)。

新增四任共用考课与处分：限期整改、留任复考、降调试用，以及证据查核、申辩、退赔和刑罚复核。罢官、下狱、流放、斩首为实际结局；普通低分和灾情不会直接触发刑罚。详见 [考课与处分说明_v0.7.md](考课与处分说明_v0.7.md)。

## 本地运行

需要 Node.js 22+ 和 Python 3，无需安装第三方依赖。

```sh
npm test
npm run test:release
npm run dev
```

打开 `http://127.0.0.1:8765`。不要直接以 `file://` 打开入口，模块和美术清单需要 HTTP。发布目录是 `dist/`，包含游戏、运行美术和离线资源配置。开发预览不缓存；访问 `/dist/` 可测试发布版的离线能力。

存档只存于当前浏览器和当前站点域名。更换设备、浏览器或从本地转到线上时，通过设置导出或复制履历，再在目标站点恢复。内嵌浏览器若未响应文件下载，可使用“履历文本备份与恢复”。
