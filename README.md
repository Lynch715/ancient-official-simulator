# 古代官员升职记 · 县府三任

[开始游戏 · GitHub Pages](https://lynch715.github.io/ancient-official-simulator/)

明代中期题材的单机地方治理模拟。玩家以进士身份外授知县，在三年156周任期内安排经济、民生、断案、工程和赈灾，考满称职后可获授府通判，再完成三年156周府级粮运任期；称职后可接任同知，统筹第三个三年156周的河工赈济。地点、人物为虚构，历史制度经过玩法简化。

## 当前可玩范围

- 三种出身、三种主角形象；按周推进的完整三年156周任期。
- 七个主要页面：公堂、辖地、案牍、钱粮、县政、官署、仕途。
- 四项工程、四宗具有固定事实的案件、县级与通用事件、灾前准备与灾后安置；另有8类周间日常。工程26周，复核2周，协济2周，采购1周，复耕反馈4周。
- 官银、仓粮、私产分账；协济、采购和复核按实际到期结算。
- 役政、市政、安民三类持续方针；四处独立辖地、人物互信与协作减费、阶段地方要务、判后执行、工程修复和欠付清偿。
- 决策与周末均有实际结算回执，列出变化前后与公私账目；预算单列为估算。
- 新增府通判可玩任期：三县调粮、常路与急运、账实核查、府仓维护、8项府级公文、考满及两任履历。
- 62 项玩法自动化测试通过，覆盖周历、v1/v2旧档迁移、年度秋收、事务原子性、重复命令、延期到账、灾情、判后执行、政策停支及完整156周治理任期。
- 12 张场景、12 张透明人物立绘、16 张头像、32 个手绘 SVG 图标；共 72 个资源 ID、100 个运行文件。按钮没有使用 Emoji。缺失素材有预留占位和自动降级。
- 自动存档、上一份备份、JSON 文件导入导出、文本备份恢复。存档版本v5；旧季度档自动换算为周，旧周制档补齐县政数据，既有钱粮、证据与选择保留。旧档已结案卷不追加执行责任。

当前可玩范围为知县、分管粮运的府通判、分管水利赈济的同知三任。知府及更高职务、留任重开仍未实现；同知结局明确标示这一范围。96 条设计种子不等于 96 个已经可以触发的游戏事件。

新增同知任期：八份公文、三项跨县工程、勘查报批和质量返工、三次汛期、口粮与复耕安置、独立专项账目。详见 [同知任职说明_v0.5.md](同知任职说明_v0.5.md)。

## 本地运行

需要 Node.js 22+ 和 Python 3，无需安装第三方依赖。

```sh
npm test
npm run test:release
npm run dev
```

打开 `http://127.0.0.1:8765`。不要直接以 `file://` 打开入口，模块和美术清单需要 HTTP。发布目录是 `dist/`，包含游戏、运行美术和离线资源配置。开发预览不缓存；访问 `/dist/` 可测试发布版的离线能力。

存档只存于当前浏览器和当前站点域名。更换设备、浏览器或从本地转到线上时，通过设置导出或复制履历，再在目标站点恢复。内嵌浏览器若未响应文件下载，可使用“履历文本备份与恢复”。

周制的季节、年与收入均为游戏简化：每季13周，每年52周，年度秋收在第39周结束时结算。

试玩包附独立的通判与同知开局体验履历。导入体验前请先备份自己的进度；体验文件不是玩家原履历。
